# 人物写真を入口にするための掲載案

写真選定は未確定。TOPの既存3作品と一覧の画像順・カテゴリは変更していない。

## 今回実装した範囲

- TOPのコピーは文節単位に区切り、スマホでは「その人と、／世界のあいだ。」の2行にする。PCでは1行のまま。
- PHILOSOPHYは既存の文章・句読点の扱いを維持し、意味のまとまりを途中で折り返さないようにする。
- 共通ナビゲーションを WORKS → PHILOSOPHY → ABOUT にする。
- TOPの代表作下に「写真作品を見る」を設け、既存の PHOTO 絞り込みへ直接つなぐ。
- ABOUTは Photographer → 現在の専門領域 → 経歴 → Creative Communicator の順にする。スマホでも専門領域を先に読めるよう、写真より文章を先に配置する。PCの文章左・写真右は維持。
- メールアドレスに「撮影のご相談」という小さな見出しを付ける。
- スライド切り替え中の写真・作品名の重なりを再現確認したため、同時フェードを順次フェードに変更する。全体の1.2秒と自動切り替え間隔は維持する。

## TOPの提案

既存の Hero.astro とスライド機能を活かし、承認後に写真3点へ絞る。最初の1点で表情と環境、続く2点で集合写真・現場への理解などを見せる。枚数を増やすより、WORKSへの導線を使って全体へ進める。

第一候補は大橋ちっぽけのアーティスト写真（01.jpg）。店内の赤いテーブル、自然光、椅子と本人の姿が同時に見え、人物と世界を結び付けるコピーに合う。

2点目の候補はOHL（01.jpg）。室内・楽器と7人の姿が一つの構図に収まり、個人写真からグループの人物撮影へ幅を広げられる。

3点目は大橋ちっぽけ「誰かのとなり」（01.jpg）、または矢井田瞳の撮影現場（01.jpg）。前者は光と振り返る表情の繊細さ、後者は現場の関係と自然な表情を見せる。後者は本人が撮影した静止画であることを最終確認したい。

映像・制作実績はWORKSの全実績一覧とABOUT後半で見せる。写真3点へ変更する際も、それらの作品・カテゴリ・URLを削除しない。

大森元貴「催し」は現在の公開データでは MOVIE、担当は編集・ディレクション、本文の Camera は Hikaru Sano。告知画像を本人撮影の人物写真として扱わない。森川本人が撮影した別の制作現場写真があれば、撮影担当・掲載可能範囲を確認して候補に加える。

## WORKSの提案

冒頭に Selected Photography を6〜9点（まず6点を推奨）。PC3列・スマホ2列で、余白と元の縦横比を活かす。画像を切り抜かず、人物の表情と周囲の空間を残す。小さな作品名を添えて詳細へリンクする。

その下に現在の ALL / PHOTO / MOVIE / PRODUCTION STAFF と全実績一覧を置く。Selected Photography は日付順やカテゴリ切り替えから独立した編集順とし、フィルタで消えないようにする。自動スライドはここには追加しない。

## 既存設計を使う実装方法

今回、選抜の空欄や仮の写真を公開画面に追加していない。承認後、次の最小構成で実装する。

1. `src/config/site.ts` に `selectedPhotography` を追加する。各項目は `{ workId, imageFile }`。作品単位の指定だけでは告知画像を避けられないため、画像ファイルも明示する。alt・タイトル・公開URL・撮影担当は既存Markdownから取得する。
2. TOPは現在の `featuredWorkIds` の順序と3件を変更する。先頭画像以外をTOPに使う場合は、こちらも `{ workId, imageFile }` を指定する方式に拡張する。作品一覧やギャラリーの画像順は変えない。
3. `SelectedPhotography.astro` を小さな部品として設ける。`getWorks`、`workHref`、既存のWebP生成処理を再利用し、画像比率を維持する。選定画像だけをサムネイル生成対象へ加え、ビルド・HTTP検証もその選定分を含むようにする。
4. WORKSのカテゴリ領域より前に表示し、`id="selected-photography"` を置く。TOPの「写真作品を見る」は `/works/#selected-photography` に切り替える。それまでは今回実装した `/works/#photo` が入口となる。
5. 未公開作品・未登録ファイル・重複選択をビルドで検出する。作品カテゴリは案件の事実として維持し、Selectedという表示上の選抜と混同しない。

## 検証結果

- 公開サイトの390px幅で、TOPの「世界」とPHILOSOPHYの「置き」の途中改行を再現した。
- 最終ビルドのローカルプレビューで、1440px・390pxのTOP、WORKS、PHILOSOPHY、ABOUT、作品詳細をブラウザ確認した。
- 390pxのTOPは「その人と、／世界のあいだ。」の2行、PCは1行。PHILOSOPHYの「必要であればカメラを置き」は分断されない。確認した各ページに横方向のはみ出しはない。
- ABOUTの専門領域は390pxの最初の画面内に表示される。PCの文章左・写真右、PHILOSOPHYの短い文章量・余白は維持。
- TOPの「写真作品を見る」から PHOTO 絞り込みへ移動できる。PCの MOVIE / PRODUCTION STAFF 切り替えも確認した。
- スライド切り替え中に2作品の写真・説明が重なる状態を再現した。修正後は前のスライドのフェード中に次のスライドが透明で待ち、切り替え後は1作品だけ表示されることを確認した。
- 既存の検証一式は成功。型検証0エラー、21テスト通過、82ページ・78作品・1395内部参照・224WebP画像のビルド検証、開発／公開プレビュー各478画像のHTTP配信を確認した。
- 実機Safari / Chromeは未検証。今回のブラウザ検証はCodex内のブラウザを指定幅に設定して行った。
- 写真は未選定のため、TOPとWORKS冒頭で人物写真の専門性を視覚的に確立できるかは、掲載写真の決定後に再確認が必要。公開サイトへのデプロイは行っていない。
